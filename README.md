# py_twin_video_duet2pic

●本ソフトについて  
・javaFXによる実装では、動画再生時に過度なメモリ消費が発生するため、Pythonでの実装に変更した。  
・１つ又は２つのファイルを左右の描画領域に展開し、フレーム単位(コマ送り・戻し)で調整して  
　立体視用のステレオ画像を静止画として取り出すためだけのツールです。  
・動画ファイルを一つ、又は二つ選択しD&Dして読み込みます。  
・左右の再生・コマ送りや再生時間スライドを使用し、立体視できる位置を探します。  
・左右の描画領域を入れ替える機能があります。  
・左右の一時停止位置(キーマーカー)を５つ保存し、呼び出すことができます。  
・左右同時再生(動作不安定なのでおまけ機能)、左右同時コマ送り機能あり。  
・立体視の位置が確定したら、保存ボタンで左右の画像を保存します。  

●実行方法・環境について  
・Pythonをインストールをしてください。  
  ※重要（Windowsの場合）: インストール時の最初の画面にある  
  「Add python.exe to PATH」 （Pythonにパスを通す）のチェックボックスに  
   必ずチェックを入れてインストールしてください。これをしていないと  
   コマンドプロンプトから pip や python が使えなくなります。  

・インストール後cmdなどを開き以下のコマンドでライブラリをインストールしてください。    
　　pip install opencv-python pillow
  
・py_twin_video_duet2pic.pyと同じ階層にあるJTwinVideoDuet2Pic.batを実行して起動します。  

・実装・実行環境：Python 3.13.15  
・使用ライブラリ：opencv-python, pillow
